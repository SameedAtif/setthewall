# Phase 2: Decor & Placement System

**Source documents:** *how_to_arrange_pictures.txt* / *at_home_with_pictures.md* / *howtoarrangepictures.pdf* (all citations below are page numbers from these).

This phase takes finished art (from Phase 1) and turns it into a validated, on-brand placement: frame, mat, grouping, and composited scene — ready for Phase 3 (e-commerce) to list and promote.

Each step in §3 is tagged with an ownership role for AI-agent use — see §6 for how to run this doc with agents, tool split, and limitations.

## 2. Rule Tables

### 2.1 Frame material (p. 16–19)
Two-step lookup: first pick the **material category**, then (if Metal) apply the color sub-table.

**Step A — material category**, by Content Type and Mood:
| Category | Character | Best fit |
|---|---|---|
| Metal | Spare, streamlined, affordable, most popular | Default for Content Type = minimalist/modern; apply color sub-table below |
| Wood | Ranges from plain/untreated and bleached/pickled (understated, modern) to natural/plain (folksy, rustic) to richly stained/polished (time-honored, classic) | Pick the sub-finish to match Mood — light/bleached wood for calm-minimalist, rich stain for calm-traditional |
| No frame / canvas gallery-wrap | Painted canvas stretched over wood supports; "fresh-from-the-studio," lets the piece speak for itself | Mood = calm, Content Type = minimalist/modern, or when the product itself is a canvas print |
| Clip frame | Clear holder, not a true frame; simple, unadorned, casual | Casual print formats (posters, prints); no-nonsense/minimal styling |
| Colored/painted frame | Intensifies the picture's color, coordinates or contrasts with the wall, or adds a splash in a neutral room | Cross-reference Color Function (§2.2a) — this is a frame-material way to execute a Color-burst or Accent-highlighter role |
| Ornate/carved | Heavy, robust outline; gilded or richly colored | Mood = bold/traditional, Content Type = detailed/representational or portrait/still-life |
| Novelty/whimsical | Shape-based (suns, moons, stars) or handcrafted material (polymer clay, tin, "tramp art") | Situational — not mood-driven, use for deliberately playful/one-off pieces rather than a repeatable style spec |

**Step B — if Metal, choose finish/color:**
| Condition | Frame material |
|---|---|
| Mood = calm + palette = warm | Gold |
| Mood = calm + palette = cool/pastel/abstract | Silver/aluminum |
| Mood = calm + palette = neutral/monochrome | Black metal |
| Mood = bold | Material follows the accent color the piece is meant to introduce (e.g. a "warm, pure-yellow" or red frame can make a piece the room's focal point, p. 26) — this table doesn't apply |

### 2.2 Frame form and contour (p. 19)
Two independent axes — both apply regardless of material category.

**Form (perimeter shape):**
| Form | Description |
|---|---|
| Angular / straight-edged | Crisp, geometric perimeter |
| Rounded / softer | Curved, gentler perimeter |
Pick form to match Mood/Content Type the same way as material — angular reads more modern/minimalist, rounded reads softer/more traditional — but the book doesn't hard-gate this one, so treat it as a style-spec choice made once per style, not a per-piece decision.

**Contour (how the sides slope, regardless of form):**
| Content type | Contour |
|---|---|
| Detailed / representational (landscapes, dense imagery) | Inward-sloping / beveled — leads the eye into the image |
| Minimalist / modern (line work, negative space, abstract) | Flush / level-plane |
| Portrait / still-life | Outward-sloping |

### 2.2a Color function (p. 82, p. 84, p. 88, p. 91, p. 97)
What job is this piece's color meant to do in the room? Pick one per scene — this drives mat and accessory choices below.

| Color role | What it does | Supporting technique |
|---|---|---|
| Accent-highlighter | Brings out an accent color already in the room that would otherwise fade | Echo the accent in the mat or a nearby accessory (p. 82) |
| Color-burst | Provides the room's single splash of saturated color in an otherwise neutral space | One saturated piece "stimulates" a whole muted room, making its understated colors feel more alive by contrast (p. 91) |
| Unifier | Ties together touches of color already scattered through the room | Use a thin, subtle mat so the picture's colors interact freely with its surroundings (p. 84) |
| Saturator | Repeats and reinforces the room's existing dominant color theme | A muted piece in a muted room reinforces calm rather than introducing tension (p. 91) |
| Line-only (no color) | Removes color tension entirely so line, pattern, and light/dark contrast carry the piece | Black/white/gray display, minimal or no color in mat/frame — "allows the lines to sing" (p. 97). This is the default color role for a minimalist/Japandi-type spec. |

**Mat intensity rule** (p. 84): a dark mat intensifies a picture's colors; a thin/subtle or off-white mat lets the picture's colors interact more openly with the room. Pick mat darkness based on the color role above — e.g. Unifier wants a subtle mat, Color-burst can support a darker mat since the piece is meant to command attention regardless.

**Wall/light interaction** (p. 84): note this scene's light direction and time-of-use if known — morning light reads cooler, north-facing rooms read colder/darker, and artificial evening light shifts color again. Bulb color temperature: cool bulbs enhance blues/grays, warm bulbs amplify yellows/reds/wood tones, frosted bulbs diffuse. This mainly matters for how a mockup scene is lit for photography — keep it consistent across a style's scene templates.

**Complementary vs. tension pairing** (p. 88): matching or softening the art's color intensity to the wall reads serene; deliberately non-complementary wall/picture color creates energy. Calm/ordered mood → complementary; bold/active mood → tension is acceptable.

### 2.2b Lighting (p. 85)
Four fixture types to choose from per scene, based on the piece, its location, and budget:

| Fixture | What it does | Best for |
|---|---|---|
| Picture lights | Attach to the frame or wall directly above/below/alongside a single piece | Individual pieces, especially where a lens-style light can spotlight black-and-white work |
| Portable floor lights | Low canisters casting light upward from the floor | A dramatic uplit spotlight effect on what's hanging above |
| Track lights | Ceiling-mounted, angled to strike specific pieces or bathe the whole wall | Multiple pictures at once, flexible re-angling if a piece moves |
| Recessed lights | Built into ceiling/wall/furniture, unobtrusive | Individual piece lighting where a clean look matters more than cost |

Bulb choice:
| Bulb | Effect |
|---|---|
| Incandescent | Warm, unobtrusive glow that brings out richness and depth |
| Halogen | Bright, intense illumination; burns hot — keep distance, use a dimmer |
| Compact fluorescent | Efficient, long-lasting; straight-tube versions work well in recessed fixtures |
| Specialty (frosted/colored/full-spectrum) | Frosted diffuses; cool-colored enhances blues/grays; warm-colored amplifies yellow/red/wood tones |

**Conservation note:** strong/direct light fades and dries out art over time. For valuable or fade-prone pieces, use UV-filtering ("conservation" or "museum-grade") glass, a UV window filter, and favor incandescent over fluorescent exposure. This is useful customer-facing guidance for how they light their print at home, not just a staging decision.

**Color-choreography technique** (p. 86): in a space with sightlines across multiple rooms, deliberately stripping color from most of the space and placing one or two bold-color pieces at key points can direct where people look first and how they move through the space — a scaled-up version of the Color-burst role (§2.2a) applied to a whole entry/hallway sightline rather than one wall.

### 2.3 Match vs. contrast (p. 20–21, p. 61)
| Wall condition | Frame approach |
|---|---|
| Neutral / plain | Match the frame to the room's materials |
| Busy / patterned | Contrast — pick a frame that reads distinctly against the pattern; don't try to blend |

**Governing principle, applies before the table above (p. 20):** choose a frame that brings out what's interesting about the *picture itself* — its drama, its tranquility, some other quality — rather than one that simply matches the room's decor. The wall-condition table is a tiebreaker for execution, not the primary driver of frame choice.

**Single piece vs. group conditional (p. 21):** matching a frame to its surroundings matters more when hanging a single piece — since a lone piece is meant to make one specific decorative contribution to the room, its frame is doing more relational work than a frame inside a busier multi-piece grouping, where the group's internal unity (§2.12) matters more than any one piece's relationship to the room.

### 2.4 Frame-to-piece sizing (p. 28–29)
- Bigger art → bigger, more substantial frame.
- Smaller art → normally a delicate, smaller frame — **unless** deliberately using an oversized/ornate frame to elevate a small piece's presence (an intentional exception, not a default).

### 2.4a Mat sizing rule (p. 21–22)
The mat should measure **visibly wider** than the frame's width — if mat width and frame width are equal, the effect reads as flat and predictable. An oversize mat around even a small piece intensifies drama; a slightly uneven mat (e.g. more area below the image than above) adds a bit of visual movement.

### 2.4b Matting technique — pick one, conditionally (p. 22–24)
| Condition | Technique |
|---|---|
| Want to add depth or accentuate one color in the piece | **Double/stepped mat** — layer one mat on top of another, revealing about ¾"–1" of the inner mat |
| Picture's shape isn't a standard rectangle, or you want to emphasize its contour | **Shape-cut mat** — circle, oval, or elongated strips instead of the standard rectangle |
| Want to intensify the picture's presence generally, no specific reason needed | **No mat** — omitting a mat entirely tends to intensify the look of whatever's being framed (p. 22); this is distinct from close framing below — a general option available for any content type |
| Content is specifically an oil-painting style/texture | **Close framing** (technical term) — the specific combination of no mat *and* no glass, standard practice for oil-painting-style work (p. 23–24) |
| Set is a narrative/chronological sequence meant to be read in order | **Multi-opening mat** — one mat with a series of openings, containing the whole sequence within a single frame rather than separate pieces (p. 100) |
| Want to punctuate or strengthen a color already present in the piece | **Colored mat** — pair with a mat that echoes/reinforces that color, rather than a neutral one (p. 22) |
| None of the above apply | Standard single mat, sized per §2.4a |

### 2.5 Single piece vs. multi-piece set vs. split-wall vs. nook vs. surface display (p. 56, p. 61, p. 63, p. 72–73, p. 80, p. 103, p. 119)
| Space math (this scene) | Action |
|---|---|
| Furniture-anchored, one piece at 2/3–3/4 furniture width fills it | **Single piece** |
| Furniture-anchored, one piece doesn't fill it, or furniture is minimal | **Multi-piece set** |
| Wide-open wall, no furniture to anchor against (e.g. hallway) | **Split-wall technique** (two options): (a) bisect the wall visually with a chair rail, border, or paint line, creating two smaller zones, each sized independently (p. 61); or (b) mount a contrasting-color backing panel behind a small cluster to "carve out a smaller space within the enormity" — a wall-within-a-wall (p. 72–73) |
| Architectural nook (window surround, chimney jog, built-in, other wall quirk) | Fit a **single piece shaped to the nook**, or a **small group**, sized to the space rather than a standard wall run (p. 56) |
| Horizontal surface (mantel, shelf, console, windowsill) — not wall-mounted at all | **Surface/propped display**: lean pieces against the wall on the surface rather than hanging (no nails needed, freely rearrangeable — "gallery-style work in progress," p. 80, p. 103); vary the height of pieces using stands, pedestals, risers, or stacked objects rather than lining them up flat (p. 119); for a multi-piece surface set, a loose triangle composition — taller/larger pieces at the back/tip, smaller in front — is a classic way to let pieces play off each other (p. 104) |

### 2.5a Space tips — line orientation and content (p. 62)
| Room condition | Technique |
|---|---|
| Narrow room | Favor art with strong horizontal lines — reads as calming and visually widens the room |
| Low-ceilinged room | Favor art with strong vertical lines — visually raises the ceiling |
| Small room, feels closed-in | A landscape with a distant/faraway vista acts as a "window" and opens the room up |

### 2.5b Location suitability (p. 42–43)
Beyond wall condition and furniture, check the scene for environmental and physical fit — relevant when recommending unglazed/textured/fiber-based print formats:
| Factor | Rule |
|---|---|
| Humidity | Avoid bathrooms/kitchens for pieces not sealed behind glass; fiber-textured or unsealed prints belong in the driest room available; glass-sealed pieces tolerate humid rooms fine |
| Heat | Avoid hanging over a fireplace in active use; avoid near heating vents (heat + dust circulation); avoid over stoves/ovens |
| Airborne grease/pollutants | Kitchens carry cooking residue in the air, not just heat — another reason to avoid unsealed/uncovered pieces there |
| Furniture/traffic clearance | Don't place pictures where moving furniture (e.g. a recliner) will strike them, in high-traffic paths already crowded with obstacles, or low enough to contact the head of someone seated on a couch below |
| Children/pets | Keep delicate or valuable pieces up out of reach of a child's arms/toys or a pet's tail/claws — treat "up high" as the default in any scene with kids or pets present |

### 2.5c Wall coverage cap (p. 51)
Default guideline: don't cover more than **two-thirds of a blank wall** with pictures. The one sanctioned exception is going fully maximalist — covering the wall (near-)completely and consistently (e.g. a full mirror- or frame-covered wall) reads as a deliberate style choice; a *partial* overreach past two-thirds reads as a mistake. Treat this as binary: stay under two-thirds, or commit fully — don't land in between.

### 2.6 Focal point — isolation vs. cluster (p. 27–28)
The book's actual mechanism is about **placement**, not mood: a piece hung off by itself, in an oversized/impressive frame, reads as the center of attention — even the simplest, sparest image will "happily act as center of attention" in isolation. The same piece placed as part of a cluster, in a thin/subtle frame, will instead "blend politely and quietly into the crowd."
- **Single piece (isolated):** focal by default. Mood sets the degree — bold mood amplifies with an oversized/impressive frame; calm mood keeps the frame quiet and lets the piece carry the statement on its own.
- **Piece inside a set:** this same lever (frame size/subtlety) is how you *reinforce* the anchor-vs-supporting hierarchy from §2.8 — give the named anchor piece the more impressive/oversized frame treatment, and deliberately thinner/subtler frames to the supporting pieces, so the visual weight matches the intended focal structure rather than fighting it.

### 2.7 Standard arrangement forms — general toolkit (p. 58–59)
These six are presented as mood-neutral standard themes — "nearly any arrangement is going to be a variation on one of the following." Pick based on the pieces and wall, not the style:

| Form | What it is | When to reach for it |
|---|---|---|
| **Tops/Bottoms in Alignment** | Align all tops or all bottoms of various-size pictures along one imaginary horizontal line | Simple groups of mixed sizes that still need one clean line to anchor them |
| **Combination Alignment** | Divide into two-plus rows; align top-row tops and bottom-row bottoms on horizontal lines, then align sides too | Larger groups of various sizes needing more structure than a single alignment line |
| **Mosaic** | No fixed grid — balance by aligning some frame bottoms with others' tops, and/or centering some pictures over others; round/octagonal frames can soften a rigid mosaic | Varied sizes/shapes with no natural row structure |
| **Four Corners** | Place the four largest pictures at the corners of the defined space; fill the middle with smaller ones | A defined rectangular area with a strong size range in the set |
| **Gallery Style** | Identical-size pictures in one long, neat row (horizontal or vertical); a taut string + pushpins can serve as a hanging guide | Sets where every piece is the same size |
| **Stair Stepping** | Align picture center points diagonally, following the line of a staircase | **Use only when the scene is a staircase wall** — this form is scenario-specific, not a general option |

### 2.7a Mood-driven layer, applied on top of a chosen form (p. 74, p. 81)
| Mood | Modifier |
|---|---|
| Calm/ordered | Favor tight, symmetric spacing; keep to one dominant frame style across the set; include "an anchoring central piece" |
| Bold/active | Salon-style is available — pictures and frames of deliberately different styles/weights/colors "poured onto the wall," bottom layer filling first (this is the one case where mixed frame language, normally forbidden in Step 4, is allowed); or a staggered Block-style (vertical–horizontal–vertical–horizontal) for gentle rotational movement instead of full salon chaos |

### 2.7b Match arrangement symmetry to subject energy (p. 68–69)
Independent of mood, check the content itself: dynamic/in-motion subject matter (action shots, energetic compositions) suits a slightly off-kilter, asymmetric arrangement; formal/still subject matter (portraits, posed or static compositions) suits precise, symmetric alignment. If mood and subject energy conflict (e.g. calm mood but energetic subject), subject energy should win on the symmetry question — use a symmetric bookend element (like matching pieces at the ends) to keep an off-kilter arrangement from feeling out of hand.

### 2.8 Count and focal dynamic within a set (p. 63, p. 74)
| Desired effect | Count | Notes |
|---|---|---|
| One dominant anchor piece, others supporting | **Odd** (3) | Name the anchor explicitly — usually the largest or strongest composition; the book calls this "an anchoring central piece" |
| No hierarchy, unified block | **Even** (2 or 4) | Reads calmer, more ordered |
| Need to flip even → odd quickly | Add one wild-card element — a mirror, carving, or hanging tile (p. 63) | Optional technique, not required |

### 2.9 Weight balance (p. 63)
- Furniture weight = dark → keep art/frame visually lighter than the furniture beneath it.
- Furniture weight = light → art can carry more visual weight without unbalancing the scene.
- Heaviness is driven by size **and** color/frame material — a small dark piece in a heavy frame can outweigh a larger pale, unframed one.

### 2.10 Eye level (p. 63)
| Room type | Eye-level rule |
|---|---|
| Seated room (living/dining) | Center 5–6" above the back of the couch/chairs |
| Hallway | At or just above eye level (no furniture-back reference) |
| General rule of thumb | Whatever height you land on, drop it 3–4" — most people hang pictures too high |

### 2.11 Spacing — three distinct rules, don't merge them
| Situation | Spacing rule | Source |
|---|---|---|
| Group of pictures to furniture below | 8–10" gap between bottom of group and top of furniture | p. 63 |
| Piece-to-piece within a general logical grouping | Several inches around each piece — too close loses individuality, too far apart loses unity | p. 63 |
| Piece-to-piece within a **theme/tribute** grouping | Tighter — pieces should appear to touch or even overlap, to visually reinforce the connection | p. 101 |
| Group width vs. furniture | Group no wider than the furniture below it; if narrower, at least half the furniture's length | p. 63 |

### 2.12 Theme unification (p. 101)
When a set is meant to read as one collection:
- **Limit the count.** Fewer pieces make the shared thread clearer and differences less distracting.
- **Similarity isn't only subject matter.** Texture, color, shape, size, intensity, or balance can all be the unifying thread instead of/alongside subject matter.
- **Proximity reinforces the connection** — see 2.11 (tight/touching spacing for theme sets).
- **Repeat, don't duplicate.** Repeat an element (frame shape, medium, palette) across the set, but avoid exact duplication — echo, don't clone.
- **Shape dominance.** If the set mixes varied shapes/formats, pick one dominant shape (e.g. rectangle) and let the others play a supporting role — this hints at hierarchy so a mixed set reads as rich rather than jumbled (p. 116–117).
- **Subdivision strategies for a large theme.** The book's own example is a big box of family photos, but the subdivision logic generalizes to any oversized collection: by phase/generation (an evolution within the theme), by sub-category (a "family branch" equivalent — e.g. sub-styles within one style), chronologically, by specific occasion/event, by room, or by season (p. 101). Use one of these to cut a theme down to a coherent, limited set rather than trying to represent the whole theme in one grouping.

## 3. Step Sequence

Phase 2 begins at Step 1, taking a finished, culled piece as input. See the Phase 1 doc for how the style spec is determined (Tracks A & B) and how the art itself is generated and culled (Track C).

### STEP 0 — Load the style spec *(weekly, once)* `[HUMAN ONLY]`
**Action:** Pull the style spec — schema defined in Phase 1 §1, values determined in Phase 1 Tracks A & B — for this week's locked style: Mood, Content Type, and Frame Form (set once for the style), plus the six per-scene axes (Wall Condition, Furniture Weight, Room Type, Room Shape/Proportion, Space Math, Color Role) for each of your 3 scene templates.
**Validation:** All three style-level axes and all six per-scene axes have values for every scene template in use this week. No blanks.

> **Note:** this spec is shared with Phase 1 — Phase 1 Track C (art generation) reads the same Mood/Content Type/Room Shape values when producing the art that arrives here as input. Step 0 is Phase 2's *loading* step, not where the values are determined.

---
**Phase 2 proper starts here.** Input to Step 1 is one finished, culled piece (or small culled set) — the output of Phase 1 Track C. Phase 2 does not generate or cull art itself.

### STEP 1 — Measure the scene, choose the placement branch *(daily)* `[AGENT-READY]`
**Action:** Check this scene's Space Math value against §2.5. Confirm the scene passes Location Suitability (§2.5b) for the intended print format, and that the planned coverage stays under the two-thirds cap or commits fully (§2.5c). Route to one of five branches:
- 1a — Single piece
- 1b — Multi-piece set
- 1c — Split-wall (wide-open, no furniture)
- 1d — Architectural nook
- 1e — Surface/propped display (not wall-mounted)
**Validation:** The branch chosen matches the measured scene, not a stylistic impulse. Scene passes location suitability and coverage-cap checks.

### STEP 2a — Single piece: confirm focal treatment `[AGENT-READY]`
**Action:** Apply §2.6 — since this piece is isolated, it's focal by default; set the Mood-driven degree (amplify vs. quiet frame).
**Validation:** Frame weight matches the Mood value.

### STEP 2b — Multi-piece set: grouping form and count `[AGENT-READY]`
**Action:** Choose a base form from the six-form toolkit (§2.7) based on the pieces and wall shape — Stair Stepping only if the scene is a staircase. Layer the mood modifier (§2.7a) on top. Check subject energy against arrangement symmetry (§2.7b) and resolve any conflict in favor of the content's energy. Then choose count and focal dynamic (§2.8). If odd count with a named anchor, plan to reinforce it with the frame-weight lever from §2.6 (impressive frame on the anchor, subtler frames on supporting pieces) — carried out in Step 4.
**Validation:** Base form fits the actual pieces (sizes/shapes on hand), mood modifier applied, symmetry checked against subject energy, and if odd count, one piece is explicitly named as the anchor. If even, none is.

### STEP 2c — Split-wall: zone the wall `[AGENT-READY]`
**Action:** Apply the chair-rail/border/paint-line technique (§2.5) to create two zones; size each zone's grouping independently using Steps 2a/2b logic per zone.
**Validation:** Each zone passes its own focal/grouping check as if it were a separate wall.

### STEP 2d — Architectural nook: fit to the space `[AGENT-READY]`
**Action:** Select single piece or small group shaped to the nook's actual dimensions, not a standard wall run.
**Validation:** Piece/group physically fits the nook's boundaries with appropriate breathing room (§2.11 piece-to-piece rule still applies if it's a group).

### STEP 2e — Surface/propped display: height and lean `[AGENT-READY]`
**Action:** For mantel/shelf/console scenes, lean pieces rather than hang; vary heights across the group using stands, risers, or stacked objects (§2.5) instead of a flat line-up; for a multi-piece surface set, arrange in a loose triangle (larger/taller pieces toward the back).
**Validation:** At least two distinct height levels are present if more than one piece is shown; no two pieces are perfectly flush unless that flatness is the deliberate look for this mood.

### STEP 3 — Unify by theme *(daily, if a set)* `[AGENT-ASSISTED — vision check, human confirms]`
**Action:** Check every piece in the set against §2.12 — limited count, shared thread (subject/texture/color/shape/size/intensity/balance), tight/touching spacing if it's a theme-tribute set, repetition without duplication.
**Validation:** Pass/fail — could a viewer tell it's the same collection at a glance?

### STEP 4 — Assign frame material and contour *(daily)* `[AGENT-READY]`
**Action:** Choose material category (§2.1 Step A) from Content Type and Mood; if Metal, choose finish/color (§2.1 Step B). Apply frame form (§2.2, set once per style) and contour (§2.2, per-piece by Content Type). Confirm match-vs-contrast (§2.3) from this scene's Wall Condition, sizing (§2.4) from the piece's actual dimensions. Choose matting technique (§2.4b) and confirm mat width against §2.4a.
**Validation:** Material category and finish both traceable to Mood/Content Type, not picked on preference. Frame choice can be justified by what it does *for the piece* (drama/tranquility/other quality), not only by what it matches in the room. Same frame language (category, form, contour) applied to every piece in a set, unless Mood = bold/salon (which explicitly allows mixing). Mat is visibly wider than frame width, not equal.

### STEP 4b — Color function check *(daily)* `[AGENT-READY]`
**Action:** Confirm this piece's Color Role (§2.2a) against the scene, set mat darkness accordingly, and check wall/light conditions if the scene template specifies them.
**Validation:** Mat choice matches the color role (subtle mat for Unifier, darker mat acceptable for Color-burst); pairing (complementary vs. tension) matches Mood from Step 0.

### STEP 5 — Check weight balance *(daily)* `[AGENT-READY]`
**Action:** Apply §2.9 using this scene's Furniture Weight value.
**Validation:** Pass/fail against the single rule — art lighter than dark furniture, or free to be heavier against light furniture.

### STEP 6 — Composite into the scene *(daily)* `[NOT AN AGENT/LLM TASK — deterministic template tool required]`
**Action:** Apply eye-level (§2.10, branched by Room Type), the 8–10" furniture gap, the group-width rule, and piece-to-piece spacing (§2.11) at the group level. Set the scene's lighting fixture and bulb tone (§2.2b) to match the Color Role from Step 4b. For any centered series, confirm placements line up along one imaginary center line (horizontal or vertical) through the group (p. 41).
**Validation:** All applicable numeric checks pass — eye level, gap, width, and internal spacing. Lighting tone is consistent with the piece's Color Role (e.g. warm incandescent glow undercuts a deliberately cool/stark Color-burst piece — check for mismatches). Group reads level and centered, not cocked or drifting off the intended axis.

### STEP 7 — Weekly review gate `[HUMAN ONLY — agent may summarize data, not decide]`
**Action:** Carry forward to Phase 3 for performance data; use it to decide whether next week's Step 0 repeats, extends, or rotates the style/scene combination.

**Output handoff to Phase 3:** this doc's Step 6 composite is the finished, placed piece that becomes Phase 3 Module 1's Step 1 input, alongside the Style Spec values it was built from. This is stated from Phase 3's side already (its Step 1); stated here too so the handoff is documented from both ends, matching how Phase 1→Phase 2 is documented on both sides.

## 5. Additional notes (not part of the daily decision tree, but worth keeping on file)

**Happy Surprises (p. 60):** the expected spot (above the couch, over the mantel) isn't the only option — the book explicitly calls out under an eave, a small cupboard door, inside a closet, or the patch of wall beneath a window as good unconventional placements. Worth offering as an alternate scene template or a customer-facing styling tip, not a rule to enforce.

**No-holes planning method (p. 57):** for customers physically hanging a print, the book's technique is to trace each piece onto paper, mark the hanger point from the actual wire/hook measurement, tape the templates to the wall, and rearrange until satisfied before hammering anything. This is a good piece of customer-education content (ties to the reciprocity/authority content strategy from Phase 3) rather than a step in your own production pipeline.

**Safekeeping / conservation checklist (p. 23–24, p. 85)** — expanded customer-education content for valuable or fade-prone pieces:
- Use acid-free materials for mat and backing (labeled conservation/museum/archival quality) — acid degrades paper-based images over time.
- Avoid displaying in rooms with heavy temperature/humidity swings (kitchens, bathrooms) or near heat sources (radiators, fireplaces, air ducts).
- Avoid direct sunlight; strong light fades and dries out art.
- For especially valuable pieces: UV-filtering ("conservation" or "museum-grade") glass, a UV window filter, and incandescent over fluorescent lighting all reduce fade risk.

**Professional framer checklist (p. 24)** — if directing customers to a custom framer rather than a ready-made frame, they should bring:
- Paint chips of the wall color (and nearby walls) the piece will hang on.
- Fabric swatches from the room's furniture/accessories.
- Color samples for the mat/frame if they already have ideas.
- Size specs (or photos) of the room and open wall area, for proportion.

**Easel display (p. 37):** a piece placed on an easel rather than hung reads as more important/elevated, and gives full placement flexibility — it can move to the center of a room, off to the side, or to a different space entirely. Worth a scene template if your product suits a freestanding, non-wall-mounted presentation (distinct from the leaning/propped surface display in §2.5 — the easel is fully mobile floor placement, not resting on furniture).

**Hanging hardware, by weight (p. 40–41):** another strong piece of customer-education content — sawtooth hangers for small/light pieces (single central point); traditional hangers or screw-eyes-with-wire for standard weight; frame hangers on both top corners for heavier pieces needing extra stability; wall anchors (screws + expanding anchor) for especially heavy pieces or hollow/masonry walls. Matching hardware to actual print weight (especially framed or canvas formats) is a legitimate trust-building tip, same category as the no-holes method.

## 6. Using this doc with AI agents

Each step above is tagged with an ownership role — `[AGENT-READY]`, `[AGENT-ASSISTED]`, `[HUMAN ONLY]`, or `[NOT AN AGENT/LLM TASK]` — so an agent reading this file (or a human skimming it) knows immediately who's supposed to act at each point, without inferring it from the prose.

### Setup
Feed the whole file (or the relevant §-range) to the agent at the start of each session rather than relying on memory across sessions — this doc is built as a lookup system specifically so the agent doesn't need to carry judgment forward, it needs the table in front of it. A Claude Project with this file attached, or a system prompt that includes it, works better than pasting fragments per request.

### The two tool types this doc needs
- **Rule lookups** (frame material, contour, matting technique, eye-level, weight balance) are deterministic — axis value in, one answer out. An LLM agent is genuinely good at this and is what the `[AGENT-READY]` tags mark.
- **Physical compositing** (Step 6: the actual 8–10" gap, 2/3–3/4 width, eye-level positioning) is math against real pixel dimensions, not a creative judgment call. This should run through a coded/template tool — pre-built scene mockups with calibrated proportions (Photoshop smart objects, Placeit, or a small script scaling/positioning art against known scene measurements) — not a generative image model asked to "put the art at the right height." Image generators approximate; they don't reliably hit precise physical constraints. Build the 3 scene templates once, with real measurements baked in, and every week's art just drops into that fixed math.

### Limitations
1. **Measurement precision.** None of this doc's numeric rules (gaps, eye level, widths) can be trusted to an image-generation model. Any "8–10 inches" claim needs a deterministic template behind it, not a prompt — this is why Step 6 is tagged `[NOT AN AGENT/LLM TASK]` rather than agent-assisted.
2. **Subjective judgment doesn't fully reduce to rules.** The doc gives criteria to screen with, not a replacement for taste. Use it to narrow the field fast (Steps 1–2), then make the final pick yourself — the chooser-vs-picker distinction only works if a human actually applies the criteria at the end, not just the agent.
3. **Style-spec drift.** Every time a new rule gets added to this doc's Rule Tables, Phase 1 §1 (which now lives in a separate file) can silently fall out of sync with it — this happened once already, before the two docs were split apart (see the axis-count fix made earlier in this project). An agent reading only one file won't catch drift against the other on its own. Worth a periodic human pass checking Phase 1 §1 against this doc's Rule Tables, same as the one that caught it originally.
4. **Customer-facing accuracy.** Anything from §5 (conservation glass, hardware weight ratings, framer checklists) that becomes actual customer content should be fact-checked before publishing — an agent summarizing this doc can smooth over details that matter when someone's hanging a real, heavy piece on a real wall.

### Where a human is required, not just preferred

This list is meant as the single cross-pipeline roll-up of every `[HUMAN ONLY]` or partially-human gate across all three phase docs — not just this one. An agent orchestrating the full pipeline should check here rather than scanning every inline tag across three files.

**Phase 1:**
- **Track A (style-level axis determination)** — the style-spec axis values themselves encode your brand's actual point of view. Letting an agent infer them defeats the purpose; this is the one place where being specific is the whole strategy, the same logic as "who's it for" — vague, agent-guessed axis values produce generic output, which is exactly what your niche is supposed to avoid.
- **Step A0's go/no-go** — the agent can run the research methodology, but reading the findings and deciding whether the style is actually worth committing a week's production to stays human.
- **Step A5 (lock the style-level entry)** — committing Mood/Content Type/Frame Form as final.
- **Step B0 (confirm the scene template is fixed)** and **Step B7 (lock the per-scene entry)** — the bookends of Track B; confirming a template is genuinely reusable, and committing its six axis values as final.
- **Track C, Step C2 (final cull)** — "would a further regeneration meaningfully beat this" is a judgment call that benefits from your eye. Agents are bad at knowing when they've hit "good enough."

**Phase 2 (this doc):**
- **Step 0 (load the style spec)** — pulling the week's locked values is mechanical, but it's tagged human because it's the checkpoint that catches an incomplete or stale spec before a week of production runs against it.
- **This doc's Step 7 (weekly review)** — real sales/view data interpretation and the repeat/extend/rotate call. An agent can summarize the numbers; it shouldn't make the call, especially early on while you're still calibrating what "working" looks like for this specific brand.

**Phase 3, Module 1 (Etsy listing):**
- **Step 7 (shipping and return policy)** — pricing/policy strategy, not observable from any input.
- Photo/title/description steps are agent-assisted with human confirmation on tone and hero-shot selection specifically — see that doc's own step tags for the exact split.
